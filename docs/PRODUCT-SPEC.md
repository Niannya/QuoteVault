# QuoteVault MVP 需求基线

## 目标

在 Windows 本地保存聊天截图，通过 OCR、群友关联和普通关键词快速找回截图，并将整张原图复制到剪贴板。

## 核心流程

1. 用户使用任意截图工具把图片放入剪贴板，随后点击收录按钮或按全局快捷键。
2. 用户也可以拖拽或批量选择历史图片。
3. QuoteVault 复制原图、计算 SHA-256 并检查完全重复的图片。
4. 离线 OCR 提取文本，生成可编辑的消息行和群昵称候选。
5. 首次出现的群昵称由用户决定创建新群友、关联现有群友或忽略。
6. 截图可关联多个群友；每条消息可单独指定发言人。
7. 用户按关键词、群友、分类或时间浏览，找到后复制整张原图。

## 身份模型

- “群友”是稳定的内部人物实体，具有内部 GUID 和用户可修改的显示名称。
- “群昵称标识”是 OCR 从截图中提取的文本。
- 群昵称首次出现时建立到群友的映射；群友改名后，新昵称再次由用户确认。
- 第一版不提供曾用名管理或头像识别。
- 用户本人和其他群友使用相同的数据模型。

## 分类模型

- 分类完全由用户创建。
- 支持任意层级的父子分类。
- 一个群友可属于多个分类。
- 截图只关联群友，不直接归属分类。
- 按分类浏览时，间接显示该分类及其子分类中群友关联的截图。

## 数据与隐私

- 所有 OCR 在本地完成。
- 图片复制到应用数据目录统一管理。
- 人工修正文本作为检索内容，同时保留原始 OCR 文本。
- 删除先进入回收站，永久删除需要再次确认。
- 完整备份包含图片、OCR、人工修正、群友、昵称映射和分类。

## 第一版明确不做

- 云端同步或云端 OCR。
- 头像识别、人脸识别。
- 语义搜索、向量搜索。
- 自动发送到 QQ。
- 移动端或网页端。
